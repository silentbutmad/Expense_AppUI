## 3. lib/ - Application Source Code

### `lib/main.dart`
- **Purpose:** Application entry point and root widget.
- **Work:**
  - Initializes Firebase.
  - Loads persisted session via `ApiService.loadSession()`.
  - Constructs `MyApp` with `ApiService` and `SupportProvider`.
  - Configures `GoRouter` with all application routes (`/splash`, `/login`, `/home`, `/reports`, `/add-expense`, `/profile`, `/register`, `/expense-details`, `/forgot-password`, `/reset-password`, `/settings`, `/help-support`, `/ticket-details`, `/ocr`, `/otp`, `/personal`, `/person-transactions`, `/transaction-detail`, `/success`).
  - Wraps app with `MultiProvider` for `ThemeProvider`, `ExpenseProvider`, `ApiService`, and `SupportProvider`.
  - Enables light/dark theming and Material 3.

### `lib/firebase_options.dart`
- **Purpose:** Auto-generated by FlutterFire CLI.
- **Work:** Provides platform-specific `FirebaseOptions` (web placeholder shown; Android should be configured with real project credentials).

## 3.1 lib/models/

### `lib/models/expense_model.dart`
- **Purpose:** Defines core data structures for financial transactions.
- **Contents:**
  - `TransactionType` enum: `received`, `paid`, `loan`.
  - `ContextType` enum: `personal`, `business`.
  - `TransactionCategory` enum: `income`, `expense`, `loan`.
  - `PaymentMode` enum: `cash`, `online`, `other`.
  - `Expense` class: Represents a financial transaction with fields like `id`, `amount`, `date`, `category`, `description`, `contextType`, `transactionCategory`, `gst`, `partyId`, `personName`, `transactionType`, `remark`, `paymentMode`, `items`, `email`, `isBorrow`.
  - `ExpenseItem` class: Represents line items within a transaction (`itemId`, `quantity`, `price`, `description`).

### `lib/models/finance_card_model.dart`
- **Purpose:** Data model for finance summary cards shown on the dashboard.
- **Contents:** `FinanceCardModel` with `id`, `title`, `value`, `icon`, and `history` (list of doubles for sparkline charts).

### `lib/models/support_models.dart`
- **Purpose:** Data models for the help & support system.
- **Contents:**
  - `TicketModel`: Support ticket with `id`, `userId`, `title`, `description`, `issueType`, `priority`, `status`, `assignedAgent`, `createdAt`, `updatedAt`.
  - `CommentModel`: Ticket comment with `id`, `ticketId`, `message`, `userId`, `userName`, `createdAt`.
  - `FaqModel`: Frequently asked question with `id`, `question`, `answer`, `category`, `createdAt`.
  - `HelpInfoModel`: Contact information (`whatsapp`, `callUs`, `email`, `workingHours`, `address`, `website`).
  - `TicketCreateRequest` and `CommentCreateRequest`: Request payload models for creating tickets and comments.

## 3.2 lib/providers/

### `lib/providers/auth_provider.dart`
- **Purpose:** State management wrapper for authentication.
- **Work:** Delegates to `ApiService` for login, session loading, and logout. Exposes `isAuthenticated` and `token` to the widget tree.

### `lib/providers/expense_provider.dart`
- **Purpose:** State management for all expense and transaction data.
- **Work:**
  - Manages personal transactions, summary data, pagination state, filters, and infinite scroll.
  - Methods: `fetchSummary`, `fetchPersonalTransactions`, `fetchTransactionsByPerson`, `fetchFilteredTransactions`, `loadMoreTransactions`, `updateSearchQuery`, `updateFilter`, `clearFilters`, `refreshAll`.
  - Helper getters: `totalBalance`, `totalIncome`, `totalExpense`, `totalLoan`.

### `lib/providers/support_provider.dart`
- **Purpose:** State management for the help & support system.
- **Work:**
  - Manages tickets, ticket details, comments, FAQs, and help info.
  - Methods: `getFaqs`, `createTicket`, `getUserTickets`, `getTicketById`, `updateTicketStatus`, `addComment`, `getComments`, `getHelpInfo`, `refreshAll`.
  - Helper methods for UI: color mapping for status/priority, date formatting, issue-type and priority label conversion.

### `lib/providers/theme_provider.dart`
- **Purpose:** State management for app theme (light / dark / system).
- **Work:** Exposes `themeMode` and methods `setThemeMode`, `toggleTheme`, `setSystemTheme`, `setLightTheme`, `setDarkTheme`.

## 3.3 lib/services/

### `lib/services/api_service.dart`
- **Purpose:** Single source of truth for all backend HTTP communication.
- **Work:**
  - Base URL: `https://expense-api-gateway.onrender.com`.
  - Centralized request methods: `_get`, `_post`, `_put`, `_patch`, `_delete` with auth token handling and 30-second timeout.
  - Auth APIs: `login`, `register`, `verifyOtp`, `resendOtp`, `forgotPassword`, `resetPassword`, `updateProfile`, `changePassword`, `logout`.
  - Expense APIs: `addExpense`, `getAllPersonalTransactions`, `getSummary`, `getTransactionsByPerson`, `getFilteredTransactions`, `getTransactionById`, `updateTransaction`, `deleteTransaction`.
  - Business/OCR APIs: `startOcr`, `confirmOcr`.
  - Support APIs: `createSupportTicket`, `getUserTickets`, `getTicketById`, `updateTicketStatus`, `addComment`, `getComments`, `getFaqs`, `getHelpInfo`.
  - Session persistence via `TokenManager` (secure storage).
  - Handles token refresh and unauthorized responses.
  - Custom exception: `ApiUnauthorizedException`.

## 3.6 lib/screens/

### `lib/screens/register_screen.dart`
- **Purpose:** New user registration.

### `lib/screens/otp_screen.dart`
- **Purpose:** One-Time Password verification.
- **Work:** Accepts OTP from user, calls `ApiService.verifyOtp`, completes registration or login flow.

### `lib/screens/forgot_password_screen.dart`
- **Purpose:** Initiates password reset.
- **Work:** Takes email, calls `ApiService.forgotPassword`, triggers reset email.

### `lib/screens/reset_password_screen.dart`
- **Purpose:** Set a new password using a reset token.
- **Work:** Accepts new password and confirmation, calls `ApiService.resetPassword`.

### `lib/screens/password_reset_success_screen.dart`
- **Purpose:** Confirmation screen after successful password reset.
- **Work:** Displays success message and redirects to login.

### `lib/screens/home_screen.dart`
- **Purpose:** Main dashboard / home screen.

### `lib/screens/expense_screen.dart`

### `lib/screens/add_expense_screen.dart`

### `lib/screens/expense_detail_screen.dart`

## Architecture Summary

- **State Management:** Provider pattern (`ThemeProvider`, `ExpenseProvider`, `SupportProvider`, `ApiService`, `AuthProvider`).
- **Routing:** `go_router` for declarative navigation with deep linking.
- **Networking:** Centralized `ApiService` wrapping `http` with secure token persistence via `TokenManager`.
- **Persistence:** `flutter_secure_storage` for auth tokens; `hive` / `shared_preferences` available for local caching.
- **Backend:** Firebase ( Core + Auth + Firestore ) configured; primary REST API hosted on Render.
- **UI/UX:** Material 3, Google Fonts, custom design tokens, Lottie animations, FL Chart for analytics.
- **Platform:** Android-first with camera, OCR, and native permission handling.
